# 📖 About

MedSchedule Pro is a Full Stack Doctor Appointment Booking System that enables patients to book appointments online while allowing administrators to manage doctors and appointments efficiently.

The project includes secure authentication, appointment scheduling, admin dashboard, AI chatbot support, MongoDB database integration, and responsive UI.
